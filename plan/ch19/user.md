# 我的初步想法

我想添加一个 node bin\embedded-mcp-toolkit-cli.js create命令，命令执行后读取 .embedded\configs\devices\board-example.yaml 文件

1.提示用户新建的设备名，用户输入后就使用这个作为设备文件名
2.提示用户输入串口的端口号、波特率、登录的用户名和密码，登录用户名和密码允许为空，为空的时候自动填none，串口的端口号也允许为空，为空时自动填none，一旦填了端口号就必须填波特率可以用COM@115200这种格式让用户一次输入，若是用户直接按下enter，那就直接填none，用户名和密码也都是直接none，用户名和密码也采用user@passwd这种格式一次输入
3.提示用户输入ssh的ip，端口(默认 22，也可以不输入)，登录用户名和密码，和串口一样分两次输入一旦输入了ssh设备的ip，后面就必须输入登录用户名和密码
4.提示用户输入adb序列号，未输入则填sn_none
