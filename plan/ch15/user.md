# 我的初步想法

src\cli\commands 中现在已经包含了sshd-config配置命令，打通了windows主机配置服务器实现服务器远程登录windows，现在我还需要windows下实现对远程服务器中全局或者指定项目中配置这个mcp的命令，敲下命令的时候，出现输入框让用户输入服务器的信息，然后是密码，实现登录，登录成功后提示用户选择配置claude/zcode，选中后让用户选择是全局配置还是项目配置

- 全局配置：查找`~/.claude.json`中的mcp配置，告诉用户当前状态，然后让用户选择是删除配置还是进行配置
- 项目配置：出现输入框，让用户输入要配置的项目的路径，查找`.claude/settings.local.json`和`.mcp.json`，查看是否已经配置和使能，告诉用户状态，然后同样是提示删除还是进行配置
